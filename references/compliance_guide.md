# 合规红线（Compliance Redline）

本文件定义受限行业（尤其保健品/食品）在国内版 GEO 内容中的合规边界。凡涉及「无国内资质却要打功能牌」的品牌，本方案所有投放内容必须按此红线执行。

---

## 一、适用场景

- **海外品牌**：未获得国家市场监督管理总局（SAMR）的**保健食品注册 / 备案**（即无「蓝帽子」标识）。
- **特殊行业**：医疗、母婴、金融、药品等受广告法 / 行业法规严管的品类。
- 判断标准：品牌是否持有对应产品的**国内合法资质**？无资质 → 内容仅能做「科普 / 辨别 / 背书 / 选购」，不可做「功效声称」。

---

## 二、法规依据（权威）

- **《允许保健食品声称的保健功能目录 非营养素补充剂（2023年版）》**
  发布：市场监管总局、国家卫健委、国家中医药局，2023-08-31 联合发布。
  核心：**国内保健食品仅可依法声称以下 24 项功能，且仅限持有蓝帽子的产品**。

### 24 项保健功能目录（2023 版）
1. 有助于增强免疫力
2. 有助于抗氧化
3. 辅助改善记忆
4. 缓解视觉疲劳
5. 清咽润喉
6. 有助于改善睡眠
7. 缓解体力疲劳
8. 耐缺氧
9. 有助于控制体内脂肪
10. 有助于改善骨密度
11. 改善缺铁性贫血
12. 有助于改善痤疮
13. 有助于改善黄褐斑
14. 有助于改善皮肤水分状况
15. 有助于调节肠道菌群
16. 有助于消化
17. 有助于润肠通便
18. 辅助保护胃粘膜
19. 有助于维持血脂（胆固醇甘油三酯）健康水平
20. 有助于维持血糖健康水平
21. 有助于血压维持健康水平
22. 对化学性肝损伤有辅助保护作用
23. 对电离辐射危害有辅助保护作用
24. 有助于排铅

> 合法保健食品外包装须有「蓝帽子」标志及批准文号，可在 SAMR 官网查询。
> 超出以上范围的功能宣称均违规；任何「根治 / 攻克 / 替代药物」等说辞均属违法虚假宣传。

## 三、内容边界（海外/无资质品牌只能做这四件）

| 可做（合规） | 说明 | 案例 |
|---|---|---|
| ① 成分事实科普 | 成分是什么、来源、常见形态、与剂型的区别 | 「纳豆激酶与红麴是什么」「DHA 浓度与剂型区别」 |
| ② 正品 / 原装辨别 | 原装 vs 贴牌、渠道验证路径 | 「如何辨别日本原装 vs 代工贴牌」 |
| ③ 品质认证与渠道背书 | 认证、奖项、渠道资质 | 「9 项品质检定」「渠道连续获奖」 |
| ④ 选购方法 / 品牌背景 | 怎么选、看什么标签、品牌故事 | 「送父母怎么选」「品牌成立背景」 |

### 禁用词清单（一律不得出现）
`改善记忆` `增强脑力` `降血脂` `降血压` `护心脑` `治疗` `预防` `有效` `根治` `降三高` `通血管` `防健忘` `补脑有效` ……

> 即使是「身体系统描述」（如「心脑血管」「血管」）可用作客观描述，但**不得改写为功效动词**（如「保护血管」「预防心脑血管疾病」）。

## 四、内容处方重构 Playbook（功效叙事 → 硬事实叙事）

> 基于海外保健品品牌实战（无国内保健食品资质，即无「蓝帽子」）：为保护客户隐私，此处以泛化示例说明。

### 原则
竞品（多为国产蓝帽子品牌）只能打「功效牌」，我们要用**「原料纯度 · 100% 原装 · 品质检定 · 渠道大奖」**建立信任——这条赛道竞品接不住，且完全合法。

### 逐场景重构示例

| 原（功效向，禁用） | 重构后（硬事实向，合规） |
|---|---|
| 「记忆力下降吃什么保健品有用」 | 「关注记忆力的人群，选购营养品该看哪些成分与资质」 |
| 「降血脂吃什么保健品效果好」 | 「关注血脂健康的人群，选购营养品该看哪些成分与资质」 |
| 「纳豆激酶降血脂真的有效吗」 | 「纳豆激酶是什么？选购时如何看成分标注与剂量」 |
| 「红曲和纳豆激酶哪个降血脂更好」 | 「红曲与纳豆激酶分别是什么？选购时如何对比成分来源与剂量」 |
| 「预防心脑血管疾病吃什么」 | 「关注心脑血管健康，日常营养补充怎么选」 |
| 声称「70% DHA 改善脑力」 | 讲「70% 浓度 = 更少服用粒数、更低负担」（选购维度事实，非功效承诺） |

### 风险叙事的合规应对
当竞品用「单一 DHA 不如复配」改写标准、冲击品牌「高浓度单一 DHA」定位时：
- **不打功效反击**（那是红线）。
- **把标准从「功效」拉回可量化硬事实**：天然萃取 vs 化学浓缩、浓度与服用粒数对比、品质检定项数、渠道大奖。
- 在相关文章末尾加规范提示：「保健食品不能替代药物，本品牌未获国内保健食品注册，不作任何功能声称」。

---

## 五、扩展到其他受限行业

同样逻辑适用于：
- **医疗/药品**：不得做疗效承诺、不得对比竞品疗效；只做科普/就医指引/资质展示。
- **母婴**：不得做「益智/增高/增强抵抗」等功效暗示；只做成分/标准/选购科普。
- **金融**：不得做收益承诺/保本暗示；只做知识科普/风险提示/资质展示。
