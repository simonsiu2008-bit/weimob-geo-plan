# 香港商業語言風格規範（hk_business）

> 對應引擎實現：`scripts/engine/lang_style.py`（TOPIC_LANG / DECK_LANG / TT_LANG 三個語言包）。
> 本文件是 `LANG_STYLE = "hk_business"` 的用語決策依據，與實現逐條對應；改用語先改語言包再更新此表。

---

## 一、定位

| 語言包 | 值 | 語域 | 適用交付物 |
|---|---|---|---|
| 大陸簡體（默認） | `mainland` | 簡體書面語，逐字保留歷史文案 | 全部 |
| 香港商業語言風格 | `hk_business` | **繁體書面語為主**（客戶可見）；銷售話術允許粵語口語色彩（內部 B 軌） | 全部 |

選擇原則：**客戶主陣地在中國香港 / 交付物以繁體呈現 / 面向香港本地管理層匯報** → 用 `hk_business`。
其他情況（內地客戶、跨境團隊共用簡體）保持 `mainland`。

---

## 二、硬性規則（不可違反）

1. **整體繁體輸出**：客戶可見交付物（PPT、話題詞 HTML）一律繁體；內部話術 `.md` 亦用繁體，
   銷售話術語句可帶粵語口語（而家 / 係 / 嘅 / 冇 / 我哋 / 畀），講稿解說部分維持書面語。
2. **品牌專名兩包一致**：「微盟星启」「微盟 Weimob」等品牌專名的寫法在 `mainland` 與 `hk_business`
   完全相同，不做繁化或改寫（品牌名是名詞不是譯文）。
3. **QA 關鍵字保持原繁體寫法**：「診斷模型估算」在任何語言包中逐字不變（QA 統計 ≥2 依賴此串）。
4. **佔位符一一對應**：兩個語言包同一鍵的 `{placeholder}` 集合必須完全一致（引擎靠 format 填數）。
5. **數據口徑句式保留**：口徑、平臺數量、KPI 公式等結構性表述只做語言轉換，不改寫語義與數字位置。

---

## 三、核心詞彙對照（mainland → hk_business）

與 `lang_style.py` 實際採用一致，新增詞條時先補語言包再補此表：

| mainland | hk_business | 說明 |
|---|---|---|
| 运营团队 | 營運團隊 | 「運營→營運」為港式最強標記詞 |
| 行业头部 / 头部 | 行業龍頭 / 龍頭 | 港式商業語境稱「龍頭」不稱「頭部」 |
| 门店 | 門市 | 零售場景 |
| 恶评 | 劣評 | 輿情場景 |
| 复测 | 複測 | 排名/基線場景 |
| 视频 | 影片 | 內容形式 |
| 搜索 | 搜尋 | 「AI 搜尋可見度」「搜尋引擎」 |
| 让你的品牌 | 令你的品牌 | 口號句式用「令」 |
| 周期表述「1–2 周」 | 「1–2 星期」 | 港式說「星期」不說「週」 |
| 天数表述「90 天」 | 「90 日」 | 港式說「日」不說「天」 |
| 每个月都能复测 | 每個月都能複測 | — |
| 「现在」 | 「而家」（話術）/「現時」（書面） | 語域分級：話術可用粵語 |
| 「我们不…」 | 「我哋不…」（話術） | 同上 |
| 记忆力下降吃什么保健品 | 適用於記憶力下降的保健品選擇 | 客戶端 HTML 避免口語疑問句 |

## 四、語域分級（hk_business 內部再分兩層）

| 層 | 交付物 | 語體 | 例 |
|---|---|---|---|
| A 層 · 客戶可見 | 20 頁 PPT、話題詞方案 HTML | 正式港式書面語，**零粵語口語** | 「國內 6 平臺平均被引用率」「行業龍頭 0.70」 |
| B 層 · 銷售內部 | `_销售话术讲稿.md` | 繁體 + 允許粵語口語色彩 | 「而家你每 100 次相關提問只有 13 次被看見」「即係錢花得對」 |

判斷標準：**客戶會不會直接看到**。同一份 `.md` 內：話術引用句（`>` 引用塊）可用粵語；
講稿解說、數據清單、合規紅線等說明性段落保持書面語。

---

## 五、稱謂與敬語

- 對客戶統一「你 / 你的品牌」（內部話術亦然），不用「貴司」堆疊敬語——港式商業文案重直接。
- 團隊自稱「微盟星启 GEO 營運團隊」（兩包僅「營運/运营」之差）。
- 行動號召用「下一步 / 今日就可以安排」，不用大陸電商腔「立即搶購」類措辭。

---

## 六、數字與單位

- 數字格式兩包一致：`53` / `13%` / `#11/18` / `0.70`，不另作本地化。
- 百分比前置數字後置 `%`，排名錨點保留 `#` 前綴（QA 銷售錨點識別依賴）。
- 涉及金額時，香港客戶案例可標 HKD；大陸口徑數據（如行業基準引用）保留原幣種標註，不換算。

---

## 七、配置方法

```python
# cases/<name>/config.py
CONFIG = dict(
    ...
    LANG_STYLE = "hk_business",   # 語言風格；省略則為 "mainland"
)
```

- 話題詞 HTML：`topic_config.py` 的 `TOPIC_CONFIG` 同樣支持 `LANG_STYLE`。
- 銷售話術：默認跟隨 `config.py` 的 `LANG_STYLE`；可 `--lang mainland` 臨時覆蓋。
- PPT / HTML 的多視覺版本與語言風格是兩個獨立維度：
  `LANG_STYLE` 管「用什麼話說」，`VISUAL_STYLES` 管「長什麼樣」，任意組合。

---

## 八、QA 影響

- 語言切換**不改變任何 QA 規則**：頁數 20 / 禁忌 0 / OOB 0 / 「診斷模型估算」≥2 / 跨 case 反查 / 合規否定語境，
  兩個語言包同標準。
- 注意簡繁同形字（化 / 你 / 搜 / 模 / 索 / 里 等）在人工抽查時不算簡體殘留；
  真正需要排查的是「们 / 视频 / 运营 / 门店 / 网络 / 内 / 市场」等簡體專用字。
