# 白話表達規範（圖表優先 · 老闆視角）

> **解決的根因**：現有方案「好專業但太多術語、搵唔到重點」，客戶老闆睇唔明，
> 後期落地時運營團隊亦接唔住。本規範適用於 PPT 全部 20 頁、話題詞 HTML、證據卡與講稿。

---

## 一、三條鐵律

1. **結論先行**：每頁先講「呢頁想講咩」（一句話），先擺數據。客戶 3 秒要抓到重點。
2. **一頁一重點**：一頁只回答一個問題。多個重點 = 冇重點。
3. **圖表優先**：能用圖唔用表，能用表唔用段落。數字要大、要少、要有對比對象。

---

## 二、術語 → 白話對照表（交付物中首次出現必須配白話）

| 專業術語 | 白話講法（配一句） |
|---|---|
| AIVO 四維評分 | 「你嘅 AI 時代成績表：四科平均分」 |
| 品牌詞可見度 | 「客戶指名問你，AI 答得出嘅機會」 |
| 品類詞可見度 | 「客戶冇指名、淨係問品類，AI 會唔會推薦你——**呢個先係新客來源**」 |
| 零價值曝光 | 「AI 提到你，但冇人搜到——等於廣告牌掛咗喺冇人嘅巷仔」 |
| 排名錨點 | 「同場競技有 N 個品牌，你排第幾」 |
| 信源引用 | 「AI 答問題時抄邊份作業——你要令自己成為佢會抄嘅嗰份」 |
| 語義場校驗 | 「你嘅內容同競品係咪出現喺同一批問題入面」 |
| 輿情健康度 | 「AI 講到你嗰陣，講嘅係好話定壞話」 |
| 基建完善度 | 「AI 搵唔搵到你嘅基本資料：官網、百科、權威報道齊唔齊」 |
| 內容佈局 | 「喺 AI 會抄嘅地方，預先放好你嘅答案」 |
| GEO 優化 | 「令 AI 推薦你嘅一整套方法」 |

> 呈現格式：`術語（白話）`——術語保留專業感，白話保證睇得明。
> 全篇只解釋一次，之後可只用白話。

## 三、圖表優先規範

| 情境 | 唔好咁做 | 要咁做 |
|---|---|---|
| 單個百分比 | 段落文字「品牌詞可見度為 0.88」 | 大數字卡：`88%` + 副行「客戶指名問，AI 答得出」 |
| 兩者對比 | 兩段文字分別描述 | 對比條：本品牌 vs 行業頭部，一綠一灰 |
| 進度/差距 | 「仍有較大提升空間」 | 進度條 + 缺口標註「差距 = 機會」 |
| 競品對比 | 長表格 + 術語列 | 3 列以內：品牌 / 位置 / 一句話差異；本品牌行高亮 |
| 痛點場景 | 裸數字羅列 | 問答證據卡（對話氣泡，見 `evidence_capture.md`） |

- 顏色語義固定：綠 = 好/本品牌，紅 = 風險/競品威脅，琥珀 = 待優化——同 palette 邏輯色一致。
- 每個數字旁邊必須有「跟邊個比」的參照（行業基準 / 競品 / 上期），冇參照嘅數字唔准單獨出現。

---

## 四、每頁「重點 + 下一步」模板（防落地困難）

每頁底部固定兩行：

```
📌 呢頁想講咩：<一句話白話結論，唔超過 25 字>
▶ 落地第一步：<運營團隊聽完就識做嘅具體動作>
```

- 「落地第一步」要具體到動作級（例：「本月內喺百家號發 3 篇 L1 話題文章」，
  唔好寫「加強內容建設」呢類口號）。
- 講稿（B 軌）同步：每頁講稿以呢兩行收尾，銷售照讀已經係完整交接。
