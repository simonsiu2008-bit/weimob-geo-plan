# 话题词框架（Topic Framework）

本文件定义「国内版 GEO 话题词方案」的方法论。该方案是微盟星启 GEO 优化方案的**第 5 份交付物**（与 PPT / 講稿 / 話術 / PDF 并列），面向客户可直接用于销售与内容排期。

---

## 一、为什么需要话题词框架

单一「可见度分数」只能测出一个数字，测不出打法。话题词框架把优化对象从「一个品牌分数」拆成「一组可操作的话题」，解决三件事：

| 层级 | 解决什么问题 | 客户感知 |
|---|---|---|
| 排名在哪 | 我在行业里排第几 | 最有感的那个数字 |
| 新客从哪来 | 用户第一次怎么搜到我 | 增量主战场 |
| 为什么敢买 | 用户凭什么信我 | 临门一脚转化 |

---

## 二、三层结构（L1 / L2 / L3）

```
L1 品类主话题 ×1  ── 锚定竞品池，产出行业排名
L2 场景话题   ×3  ── 新客第一次接触品牌的入口，增量主战场
L3 信任话题   ×1  ── 临门一脚，解决「敢不敢买」，差异化背书兑现场
```

### L1 · 品类主话题（×1）
- 同时覆盖品牌主力产品线，范围比「保健品」窄（竞品池可控）、比单品词宽（不被儿童/细分稀释）。
- 用途：竞品池锚定 + 行业排名产出（客户最关心的数字）。
- 反例：「保健品」太宽、「DHA」太窄且被儿童场景稀释。

### L2 · 场景话题（×3）
- 新客入口，按「人群 × 场景 × 意图」拆解，不按品类拆解。
- 典型三类：**送礼决策 / 症状-方案 / 健康管理-成分**。
- 优先级按竞品占位空白度排序（空白越大、增量越高）。

### L3 · 信任话题（×1）
- 临门一脚。对海外/原装/品质型品牌尤其关键——这是其资质资产唯一能被完整兑现的语义场。
- 内容方向：正品 vs 贴牌辨别、品质认证、渠道背书、品牌背景。

## 三、五问测试（话题值不值得投钱）

每个候选话题必须逐条通过：

| # | 测试 | 失败判定 |
|---|---|---|
| 01 | **竞品召回** | 用该话题问 AI 不能稳定返回 ≥5 个品牌名 → 产不出排名，话题作废 |
| 02 | **品牌纯净** | 话题或派生问题含自家品牌名 → 可见度虚高、无法与竞品同口径对比 |
| 03 | **叙事一致** | AI 回答语境与品牌核心叙事不同源 → 外来户，投产比极低 |
| 04 | **意图深度** | 落在科普层 < 对比层 < 选购层；纯科普型话题商业价值低 |
| 05 | **内容可执行** | 不能翻译成「写什么文 + 发哪个平台」→ 监测了也无法优化 |
| 06 | **合规校验** | 该话题下我方要发的内容，能否不写任何功效仍成立？落不了地（必须声称功效才能赢）的话题，对受限行业是雷区，弃用或换角度 |

> TEST 06 为合规增强项，对保健品/医疗/母婴/金融等受限行业必做。

## 四、20 题监测池（可复测基线）

- 全部为**纯品类词 / 场景词，零品牌名**（含品牌名会让 AI 必然答出品牌，可见度虚高且不可对标）。
- 结构：L1 ×4 + L2 ×12（3 场景各 4）+ L3 ×4 = **20 题**。
- 监测口径：`场景数 = 问题数 × 平台数` → 20 × 国内 6 平台 = **120 个可监测场景**。
- 每题附「意图类型」与「我方内容边界」两列：
  - **意图类型**：品牌筛选 / 榜单型 / 选购指导 / 症状求解 / 成分对比 / 信任验证 …
  - **我方内容边界**：标记该问句是「可监测竞品」还是「内容红线」——我方只监测竞品怎么说，自己绝不跟着声称功效。

### 公式透明（必须写进方案）
```
话题可见度 = 命中该话题的场景数 ÷ 该话题场景总数 × 100%
```
全部问题不含品牌名，确保数据可对标、可复测。

## 五、语义场校验（避免选错话题）

同一行业存在多个语义场，必须校验候选话题与品牌叙事是否同源：

- **案例**：某日本原装 DHA 品牌，曾被建议做「香港保健品推荐」。
  实测该话题 AI 召回的是位元堂 / 余仁生 / 衍生 / 东方红 / 保心安 / CATALO 家得路——属**港式中药滋补**语义场，与「日本原装製造 + 高浓度 DHA」不同源。
  → **结论**：不纳入国内版主话题；如需覆盖港澳/代购客群，作为独立港澳版防守话题单独监测。
- **正解**：改用「日本进口保健品」「日本原装保健品」等同源语义场。

**校验方法**：用候选话题问 AI，看召回的竞品是否落在品牌核心叙事的同一语义场；不同源则降级或弃用。

## 六、交付节奏（三阶段）

| 阶段 | 周期 | 重点 | 交付数字 |
|---|---|---|---|
| P1 建立基线 | 1–2 周 | 20 题 ×6 平台跑测，产出可见度与竞品排名 | 话题基线报告（含行业排名） |
| P2 抢占高优 | 3–12 周 | 榜单文矩阵 / 标准反写专题 / 官网结构化改造 | 高优话题可见度 0 → 首次进榜 |
| P3 扩面固化 | 13–24 周 | 补齐剩余话题 / 信源回流 / 月度复测 | L1 品类话题进入行业前十 |

> 所有内容须守住合规红线（见 `compliance_guide.md`）。
